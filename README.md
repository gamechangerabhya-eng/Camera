# Portrait Studio Pro - Media Edition

- Capture and save processed photos
- Record the final composited canvas and download video
- Built-in image backgrounds
- User-uploaded image backgrounds
- User-uploaded video backgrounds that animate behind the segmented person
- Separate image/video segmenters, controlled realtime inference, camera cleanup, responsive interface

Video output uses the best MediaRecorder MIME type exposed by the current browser. The downloaded extension is WebM or MP4 according to the selected recorder MIME type.
